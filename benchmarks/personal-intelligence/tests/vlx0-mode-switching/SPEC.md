# vlx0-mode-switching

## Purpose

Test whether VLX-0 can shift interaction mode with the same user without collapsing the relationship into one global style.

The sequence moves from adversarial research, to explicitly off-duty casual banter, then back to the same methodological dispute.

The factual standard must remain stable and temporary casual-mode instructions should not become a durable global relationship rule.
